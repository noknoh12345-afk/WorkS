# 本スキャン (BookScan)

iPhone だけで本や書類をスキャンし、1冊の「本」としてまとめて、ページをめくって読める iOS アプリ。

## 主な機能

- **メモアプリと同じスキャナー**（VisionKit `VNDocumentCameraViewController`）で連続撮影・自動枠検出・台形補正
- **非破壊の画質補正**：オリジナル / 補正カラー（影除去・背景白色化）/ グレー / 白黒。元画像は常に保持
- **本としてまとめる**：本棚（分類）・表紙設定・綴じ方向（左綴じ / 右綴じ）
- **整理**：並べ替え・まとめて削除・順番の反転・途中への挿入・撮り直し差し替え・本どうしの結合・回転
- **読書ビュー**：紙をめくるページカール / スライド、ピンチ・ダブルタップ拡大、続きから読む
- **文字認識（日本語・英語、端末内）**：全ページの本文を本棚から検索、ページのテキストをコピー
- **書き出し**：文字検索できる PDF（画像は再圧縮なし）、JPEG 画像、テキスト
- 写真アプリからの取り込み（書類の自動切り抜き付き）
- 「ファイル」アプリから元画像にアクセス可能

## ビルド

`main` に push すると GitHub Actions（macOS）が未署名 IPA をビルドし、Release の `latest` に置きます。

ローカル（macOS）:

```sh
brew install xcodegen
xcodegen generate
open BookScan.xcodeproj
```

要件: iOS 17 以降 / Xcode 16 以降

## インストール

未署名 IPA なので、Sideloadly・AltStore・TrollStore などで自分の Apple ID で署名して入れてください。
